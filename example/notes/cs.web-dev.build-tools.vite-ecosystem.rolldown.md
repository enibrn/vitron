Rolldown is a modern JavaScript bundler inspired by Rollup and optimized for the Vite ecosystem. It aims to provide fast build times, efficient code splitting, and a flexible plugin system. Rolldown is suitable for both libraries and applications, supporting advanced features like tree-shaking, dynamic imports, and seamless integration with modern frontend workflows.
