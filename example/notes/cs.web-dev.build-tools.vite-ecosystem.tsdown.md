Tsdown is a documentation generator for TypeScript projects. It parses TypeScript code to extract type information, comments, and API signatures, producing structured and readable documentation. Tsdown is ideal for maintaining up-to-date docs in large codebases, supporting custom themes, Markdown output, and integration with modern CI/CD pipelines.
